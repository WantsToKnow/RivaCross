l1: crosshair character
l2: position x
l3: position y
l4: size
l5: color in #rgb hex format
l6: hotkey mode (optional; 0=disabled, 1=hold, 2=toggle)
l7: hotkey VK code (optional; decimal; F1=112 F2=113 ... F12=123)
l8: hotkey modifier mask (optional; 0=none, 1=Ctrl, 2=Shift, 4=Alt; add values to combine)
